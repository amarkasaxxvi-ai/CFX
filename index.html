📋 CARA SETUP EA BRIDGE
  1. Download EA "Shelen_Bridge.ex5" dari Admin via WA.
  2. Attach EA ke chart mana saja di MT5 (timeframe bebas).
  3. Di Input Parameter EA: set Port = 8080 (atau custom).
  4. Allow WebSocket: Tools → Options → Expert Advisors → Allow WebRequest.
  5. EA akan start server. Masukkan URL di atas dan klik CONNECT.

Payload format EA → Bridge:
{"type":"tick","symbol":"XAUUSD","bid":2345.12,"ask":2345.34,"spread":0.22}
{"type":"account","balance":10000,"equity":9820,"margin":180,"freeMargin":9640,"drawdown":1.8}
{"type":"positions","data":[{"ticket":123,"symbol":"XAUUSD","type":"buy","volume":0.1,"profit":34.5}]}

SYARAT & KETENTUAN

1. DEFINISI

SHELEN adalah platform terminal trading berbasis AI yang menyediakan sinyal, analisa, dan alat bantu trading. Pengguna adalah individu yang mendaftar dan menggunakan layanan SHELEN.

2. RISIKO TRADING

Trading forex, komoditas, dan aset keuangan mengandung risiko kerugian yang signifikan termasuk kemungkinan kehilangan seluruh modal. SHELEN tidak memberikan jaminan profit. Semua sinyal dan analisa bersifat informatif dan bukan rekomendasi investasi. Pengguna bertanggung jawab penuh atas keputusan trading mereka.

3. PENGGUNAAN PLATFORM

Pengguna dilarang menggunakan platform untuk aktivitas ilegal. Akun tidak dapat dipindahtangankan. SHELEN berhak menangguhkan akun yang melanggar ketentuan tanpa pemberitahuan sebelumnya.

4. PEMBAYARAN & REFUND

Pembayaran plan dilakukan via transfer bank atau QRIS. Tidak ada pengembalian dana (refund) setelah plan diaktifkan, kecuali terdapat kesalahan teknis yang terbukti dari pihak SHELEN.

5. PRIVASI DATA

Data pengguna (akun, trade journal, preferensi) disimpan secara lokal di perangkat pengguna (localStorage). SHELEN tidak mengirimkan data pribadi ke server pihak ketiga tanpa persetujuan eksplisit pengguna.

6. MT5 BRIDGE

Koneksi MT5 Bridge bersifat peer-to-peer antara aplikasi SHELEN dan EA di MetaTrader 5 pengguna. SHELEN tidak menyimpan atau mengakses data akun MT5 pengguna. Keamanan koneksi sepenuhnya menjadi tanggung jawab pengguna.

7. PERUBAHAN KETENTUAN

SHELEN berhak mengubah ketentuan ini sewaktu-waktu. Penggunaan berkelanjutan dianggap sebagai persetujuan terhadap perubahan tersebut.
